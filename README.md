# Beauty Salon Management System

Система управления салоном красоты с панелью администратора. Позволяет вести учет клиентов, мастеров, услуг и записей на прием.

---

### Стек технологий
* **Язык:** Java 17+ (или ваша версия)
* **Фреймворк / Библиотеки:** Spring Boot / Hibernate (JPA)
* **База данных:** PostgreSQL / MySQL
* **Сборщик:** Maven / Gradle

---

### Основной функционал

#### Для клиентов / пользователей:
* Просмотр каталога услуг и прайс-листа.
* Выбор мастера, даты и доступного времени.
* Создание и отмена онлайн-записи.

#### Панель администратора (Admin Panel):
* Управление мастерами (добавление, график работы, специализация).
* Управление услугами и категориями (цены, длительность процедур).
* Просмотр расписания записей и изменение статусов (подтверждено / завершено / отменено).
* Базовое управление клиентской базой.
